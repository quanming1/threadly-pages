# Threadly Pages

This repository contains the public static build of [Threadly](https://github.com/quanming1/threadly). The application source remains in the private repository; generated JavaScript and browser assets are public as required for a public GitHub Pages site.

The application stores learning data in the visitor's browser IndexedDB. Python judging requires a separately hosted service and is unavailable on this static site.

This build was generated from source version 0.1.0, commit `63cea0d`, and is served at <https://quanming1.github.io/threadly-pages/>. Rebuild from the private source repository and submit the generated site as a Pull Request to update this deployment.
